PRINTING SETTINGS REFERENCE
===========================

FOR CHROME OR CHROMIUM:
  1. Press Ctrl+P (Windows/Linux) or Cmd+P (Mac)
  2. Choose "Save as PDF" in Destination
  3. Settings:
     - Margins: None (or Minimal)
     - Scale: 100%
     - Page size: A4 (210mm x 297mm)
     - Orientation: Portrait
     - Background graphics: OFF (to save ink)
  4. Click "Save"
  5. Choose filename and location

FOR EDGE BROWSER:
  1. Same steps as Chrome (uses same engine)

FOR SAFARI:
  1. File → Export as PDF
  2. Verify margins are minimal
  3. Page size should auto-select A4

FOR FIREFOX:
  1. File → Print (Ctrl+P or Cmd+P)
  2. Choose "Print to File" or "Save as PDF"
  3. Verify page settings (Portrait, A4, margins)
  4. Save

TROUBLESHOOTING
===============

PROBLEM: PDF shows fewer than 75 pages
SOLUTION: Try Chrome browser (most accurate rendering)
          Check print margins (set to None)
          Verify print scale is 100%

PROBLEM: Text appears too small in PDF
SOLUTION: Increase print margins to 0.5" to 1"
          Adjust browser zoom (try 110% if needed)
          Try different browser

PROBLEM: Some content missing in PDF
SOLUTION: Check print settings (Background graphics: ON)
          Try printing from different browser
          Ensure full HTML file is saved and uncorrupted

PROBLEM: Page breaks look awkward
SOLUTION: This is expected due to content density
          Page breaks placed automatically by browser
          Can manually adjust via CSS if needed

PROBLEM: Customized text doesn't show
SOLUTION: Ensure you saved the HTML file after editing
          Refresh browser (Ctrl+R or Cmd+R)
          Clear browser cache if needed
          Try in different browser
