## 📍 The 6 Things to Replace

Using your text editor's Find & Replace (Ctrl+H):

| Placeholder | Replace With |
|---|---|
| `[Student Name]` | Your full name |
| `[Registration Number]` | Your university registration ID |
| `[Guide Name]` | Your project guide's name |
| `[Institution Name]` | Your college/university name |
| `October 2026` | Current month/year (if different) |

**Pro tip:** Use Find & Replace in VS Code:
- Ctrl+H to open Find & Replace
- Type placeholder name in "Find"
- Type replacement in "Replace"
- Click "Replace All"

## 🖨️ How to Print to PDF

### Method 1: Chrome (Recommended)
1. Open `FORMAL_PROJECT_REPORT.html` in Chrome
2. Press `Ctrl+P` (or `Cmd+P` on Mac)
3. Under "Destination" select "Save as PDF"
4. Settings: Margins=Default, Paper=A4, Orientation=Portrait
5. ✓ "Background graphics" should be checked
6. Click "Save" and choose location

### Method 2: Edge
Same as Chrome (Edge has identical print to PDF)

### Method 3: Firefox
1. File → Print
2. Print to file as PDF
3. Note: Some formatting may shift slightly

### Method 4: macOS Preview
1. Open in Safari or Preview
2. File → Print
3. PDF dropdown (bottom left) → Save as PDF

## 📝 Common Questions

**Q: Can I add or remove sections?**  
A: Yes. Read the customization guide for how to add pages.

**Q: Should I add screenshots?**  
A: Recommended! After any section title, add:
```html
<img src="path/to/screenshot.png" style="max-width: 100%; border: 1px solid #ddd;">
<p><em>Figure 1: Voter Portal Login</em></p>
```

**Q: Can I convert to Word?**  
A: Yes, but formatting may shift. Print to PDF from the HTML (most reliable).

**Q: What if my tech stack is different?**  
A: Edit Section 3.1 with your actual technologies.

**Q: Should I include source code?**  
A: Brief examples in appendix. Full code → link to GitHub.

**Q: What format should the filename be?**  
A: Suggest: `Vote_Anywhere_Project_Report_[YourName].pdf`
